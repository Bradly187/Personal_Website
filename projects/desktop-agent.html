Personal Desktop Agent

Personal, local-first agent operating system for adaptive accessibility. A single-user AIOS kernel — real-time sensor scheduler, behavioral twin, semantic memory, tool manager, and privacy gate — enabling hands-free Windows control through voice, head tilt, and touch. Built to solve a real problem: computing access under non-stationary motor capability.

Diagram 2
Input Modalities
Head Tilt (L515)
Intel RealSense L515 depth camera tracks head tilt angle at 60Hz to drive cursor position. One-Euro adaptive filter suppresses tremor. Pain-day mode relaxes speed thresholds automatically.
Stack: pyrealsense2 · One€ filter · depth-to-angle mapping
Voice Commands
Wake phrase "hey agent" arms a 15-second window. Whisper large-v3 on GPU transcribes. Acoustic profiler adapts VAD per user voice condition.
Stack: faster-whisper · Silero VAD · Acoustic profiler
Touch / Trackpad
Full multi-touch trackpad on iPad screen. Direct touch commands bypass the LLM entirely for zero-latency control.
Stack: SwiftUI TrackpadView · WebSocket bypass

All 16 verbs flow through CommandExecutor. DomainClassifier gates the pipeline — simple commands go to llama3.1:8b (verb-first); dev-domain queries go to DevAgent, which selects a specialist model. MOUSEDOWN/MOUSEUP execute synchronously for timing-critical drag operations.
Diagram 5
5-Gate Routing Pipeline (Gate 0 + Gates 1–4)
G0
Gate 0 — Privacy Screen
Detects sensitive patterns (passwords, API keys, SSNs, card numbers) and forces local inference silently so nothing sensitive ever leaves the machine.
→ force local or pass
G1
Gate 1 — Confidence
Whisper logprob ≥ −1.0 or head tilt confidence ≥ 0.60. Low-confidence voice triggers re-transcription rather than guessing.
→ pass or cloud fallback
G2
Gate 2 — Complexity
Token-count proxy ≤ 40 words for the fast local path. DomainClassifier routes dev-domain queries (CODE/MATH/VISION/PLAN) to a specialist model via ModelRouter.
→ local candidate or specialist
G3
Gate 3 — VRAM
≥ 8 GB free VRAM required (absolute floor, not a percentage) — tuned for an RTX 5090 running Whisper large-v3 alongside the resident LLM.
→ local or cloud fallback
G4
Gate 4 — Latency Budget
Estimated local latency must beat the source modality’s target. Local: llama3.1:8b, verb-first, ~190ms warm; 15s circuit-breaker → CLARIFY. Cloud: claude-haiku-4-5 (command) / claude-opus-4-8 (dev), 10s timeout.
→ local execution or Anthropic API
After routing, CommandExecutor maps each verb to an MCP tool call. ActionVerifier does a perceptual diff (pre/post screenshot) for CLICK, OPEN, CLOSE, and SCROLL; UIAutomation finds targets by fuzzy name. An ack + status reply streams back to the iPad.
