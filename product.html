// What it does
Conversational Scheduling
Patients and staff interact with a Google Gemini-powered AI agent to book, modify, and cancel appointments in plain English. The agent resolves conflicts, enforces business rules, and confirms in real time.
Patient Intake & Triage
Collects reason for visit, urgency signals, and relevant history during the scheduling flow. Structured intake data is stored and available to providers before the appointment.
Appointment Management
Full CRUD with conflict detection, recurring scheduling, and automated waitlist management. Calendar integration hooks expose appointment data to external systems.
Role-Based Access
Five permission levels: Admin, Provider, Staff, Patient, and Auditor. Each role sees only the data and actions relevant to their function, enforced at the API layer.
TOTP Multi-Factor Auth
Time-based one-time passwords for all user accounts. HIPAA-style audit logging captures every data access and modification event with timestamps and actor identity.
Automated Waitlist
When an appointment opens, the waitlist engine automatically identifies and notifies the next eligible patient — no manual tracking required.
// Integration options
MCP Server
Model Context Protocol
Connect any MCP-compatible LLM client directly to clinic data and workflows. Exposes four tool endpoints: schedule appointment, get availability, update appointment, and retrieve patient context. Drop into an existing agentic pipeline in minutes.
REST API
HTTP / JSON API
Nine controller endpoints covering appointments, patients, providers, availability, and the waitlist. JWT authentication, standard HTTP status codes, and structured JSON responses. Works with any language or framework that can make HTTP requests.
Included UI
Blazor Web Application
A complete Blazor Server + WASM hybrid front-end for clinic staff. Provides scheduling management, provider calendars, patient records, and the AI scheduling chat interface — no custom UI required to go live.

Small clinic operators
Replace manual phone scheduling with an AI that handles intake, conflict resolution, and patient communication. Staff access a full-featured web UI; patients interact with the AI in natural language. Production-ready infrastructure included — no devops required to get started.
